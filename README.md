
# Banking Loan Default Prediction

## Project Overview

This project develops an end-to-end Machine Learning
application to predict the probability of loan default
using banking customer and loan information.

The objective is to build a reusable and professional
Machine Learning pipeline covering the complete process
from data ingestion to customer-level prediction.

## Project Objectives

- Analyze banking customer and loan information.
- Perform exploratory data analysis.
- Prepare and transform datasets.
- Train multiple Machine Learning classification models.
- Evaluate and compare model performance.
- Predict loan default probabilities.
- Deploy the trained model through a web application.

## Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Flask
- Git and GitHub
